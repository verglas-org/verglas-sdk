Verglas has exactly nine products: Worker, Durable Object, Stream, Pipeline,
Sink, Catalog, Vectorize, Graph, and Query. Worker is stateless. Durable Object is a Turso-backed
stateful Worker class. Stream, Pipeline, Sink, Catalog, Vectorize, Graph, and Query are prebuilt
Worker/DO deployments. Read the [normative platform
page](/docs/architecture/primitives-platform) for the complete definitions and
PP1–PP10 criteria.

The same repository contains the Wasmtime runtime, Foyer cache, origin access,
Iceberg commit capability, and Catalog libraries shared by those products.
These are implementation layers, not extra products.
